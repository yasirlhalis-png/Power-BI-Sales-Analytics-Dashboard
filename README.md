# 📊 Executive Sales Analytics Dashboard (2025–2026) | Power BI

A high-performance, dark-themed **Power BI Sales Dashboard** designed for executive decision-making, visual clarity, and seamless interaction. The project transforms transactional sales data into dynamic business insights using advanced data modeling, custom slicer visuals, and standardized metric formatting.

## 🔑 Key Features & Highlights

- **🎛️ Interactive Supervisor Slicer Panel:** Customized passport-style image slicers with tailored hover and selected state styling for fast user interaction.
- **🔗 Relational Data Modeling:** 1-to-Many data relationships connecting `Supervisor` and `State_list` dimensions to the primary `Sales_Data` table.
- **📊 Key Performance Indicators (KPIs):** Instant executive visual tracking for `Total Sales`, `Total Cost`, `Total Profit`, `Total Quantity`, and `Transactions`.
- **🗺️ Regional & Category Analytics:** Interactive location map paired with category-wise sales volume breakdowns and brand-wise revenue share.
- **🎨 UI/UX Excellence:** Dark steel-grey contrast palette (`#5C6B73`, `#3D4850`) optimized for low-eyestrain reporting and professional showcase.

## 🛠️ Tech Stack & Methodology

| Component | Technology | Description |
| :--- | :--- | :--- |
| **Data Engine** | Power BI Desktop | Core analytics dashboard environment |
| **Data Cleaning** | Power Query | Schema structuring, column typing, and dataset preparation |
| **Data Modeling** | Relational DAX / Star Schema | Established active 1-to-Many relationships for dynamic filtering |
| **Visual Design** | Custom UI Grid Layout | Steel-grey aesthetic with hover micro-interactions |
